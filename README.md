# 🤖 AI Placement Preparation Chatbot

An AI-based placement preparation chatbot developed using Python, NLP, and Machine Learning.

## 🚀 Features

- Real-time chatbot interaction
- NLP-based text preprocessing
- Intent classification using Machine Learning
- TF-IDF Vectorization
- Streamlit-based interactive UI
- Technical interview preparation support

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- NLTK
- Pandas
- NumPy

## 📚 Topics Covered

- Python
- DBMS
- OOPs
- Machine Learning

## 📂 Project Structure

```bash
AI_Chatbot/
│
├── app.py
├── intents.json
├── train_model.py
├── chatbot_model.pkl
├── vectorizer.pkl
```

## ▶️ How to Run

Install required libraries:

```bash
pip install streamlit nltk scikit-learn pandas numpy
```

Run the chatbot:

```bash
python -m streamlit run app.py
```
